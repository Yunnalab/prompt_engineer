## L1 - 生成式软件工程导论

核心内容：

- **四次技术革命**：PC → 互联网 → 移动互联网 → AI，每次都是昂贵能力变成日用品
- **AI 时代的焦虑**：AI 替我上大学、学会的东西 AI 都会做、简历同质化
- **课程定位**：软件工程实践课，Token 自费政策
- **LLM 的本质**：token 预测而非记忆，背景知识 + 临时记忆
- **软件工程失败的本质**：Intent → Specification → Implementation 的翻译错误
- **AI 的局限**：做题家思维，缺乏工程品位
- **核心竞争力**：找到值得解决的问题，把未知拆成便宜的实验

## L2 - 提示词工程

核心内容：

- **提示词的历史演变**：从 GPT-2 的"续写条件"到 GPT-3 的"任务说明"
- **提示词不止在对话框**：Agent 看见的是一整个上下文（Context）
- **从提示词工程到上下文工程**：关心每次决策前哪些 token 以什么来源、顺序和作用域出现
- **提示词的五层结构**：System Prompt → User Prompt → Project Prompt → Skills → Tool Schema
- **上下文工程**：让模型知道"完成"是什么，通过 V(τ)=1 判据实现停机
- **Greenfield 悖论**：大型复杂系统 AI 游刃有余，从零开始反而容易翻车
- **少干预反而做得更多**：优化 throughput 而非 latency
- **Test-time Scaling**：用算力换智力，把灵感改造成搜索
